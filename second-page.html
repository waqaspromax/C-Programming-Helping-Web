What is Programming?

Programming is a way of communicating with computers by giving them instructions to perform specific tasks.Just like we use languages such as Urdu , Hindi or English to communicate with each other, programming languages allow us to communicate with computers and tell them what to do.

What is C?

C is one of the oldest and most powerful programming languages. It is known for its speed, efficiency,and close interaction with computer hardware.It was developed by Dennis Ritchie at AT&T Bell Labs in 1972 and has influenced many modern programminf languages.

Uses of C

  1. Used to build operating systems such as Windows, Linux, and other low-level system software
  2. Commonly used for writing device drivers and programming embedded systems.
  3. Suitable for microcontrollers, cameras, IoT devices, and memory-constrained systems.
  4. Ideal for applications where high performance, speed, and low latency are critical.

C Programming Handbook Variables, Constants & Keywords

Variables

A variable is a named container that stores a value in memory. Variables make programs flexible because their values can change while the program is running

Example

int a = 3; float b = 4.7; char c = 'A';

Rules for Naming Variables

  1. The first character must be an alphabet or underscore (_).
  2. Numbers are allowed, but not as the first character.
  3. Only underscores are allowed as special characters.
  4. Variable names are case-sensitive.
